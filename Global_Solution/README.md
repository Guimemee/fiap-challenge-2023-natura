# 🌐 Global Solution 2023 — Combate à Fome (1S) & Saúde Global Hapvida (2S)

## 🌱 1º Semestre: Fome Zero e Agricultura Regenerativa
Soluções integradas de engenharia para aumento da produtividade agrícola e redução de desperdício:
1. **Algoritmos de Alta Performance (Java)**: Sistema `AutomaticSoilAnalysis` com telemetria contínua de 20 sensores de solo (pH, umidade relativa e parâmetros agronômicos).
2. **Termodinâmica Aplicada**: Análise Exergética (1ª e 2ª Leis da Termodinâmica) para controle biológico de pragas em lavouras.
3. **Engenharia Eletrônica**: Suplementação luminosa com LED Grow automatizado para estufas urbanas.
4. **Cálculo Multivariáveis**: Modelagem diferencial e integrais de escoamento para reservatórios de irrigação.

## 🏥 2º Semestre: Desafio Hapvida (TechCare4All)
* Plataforma de monitoramento preventivo de saúde utilizando sensores vestíveis (*smart wearables*) e telemetria hospitalar.
